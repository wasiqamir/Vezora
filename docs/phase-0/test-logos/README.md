# Sample logo test set

Original fixtures for reconstruction. They are not real brands. Upload the raster file, not the SVG. The SVG is the known design so a later test can compare structure.

PNG and JPG files are generated by `generate.ps1` on Windows. The product font list does not include Segoe UI. These fixtures use it only so the rasterizer has a font.

## Cases

| File | Case | What v1 should do |
|---|---|---|
| `01-monochrome.png` | One black mark and the words NORTH / STUDIO on white | Editable paths plus a text candidate. Keep the original locked. |
| `02-multicolor.png` | Flat green, orange, and yellow shapes plus PINE / GOODS | Separate flat colors, plus a text candidate. |
| `03-text-heavy.png` | Mostly type: HARBOR LEGAL GROUP and a service line | OCR candidates for the main lines. A missing path is acceptable. |
| `04-transparent.png` | Blue kite and the word KITE, no background | Keep transparency. Do not invent a white background. |
| `05-gradient.png` | Circle with a blue gradient and the word AURORA | Do not crash. An exact gradient is not required. Keep the original locked and warn that the draft is approximate. |
| `06-low-resolution.jpg` | The multicolor logo scaled to 96×96 and saved as a low-quality JPEG | Do not crash. Coarse paths or a failed draft are both acceptable if the original stays on the canvas. |

`01` and `02` are the supported samples in the MVP acceptance criteria. `05` and `06` are the graceful-failure samples. `03` and `04` must run without a crash and must not drop the original image.

## Regenerate

From this folder:

```powershell
powershell -ExecutionPolicy Bypass -File .\generate.ps1
```

The script writes the six raster files into `files\`. The SVG sources in `files\` are written by hand and are not overwritten.
